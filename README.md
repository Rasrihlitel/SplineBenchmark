# SplineBenchmark

## Постановка задачи
**Дано:** набор узлов интерполяции $(x_i, y_i)$, $i = 0, \dots, n-1$, 
где $x_0 < x_1 < \dots < x_{n-1}$.

**Требуется:** построить кубический сплайн $S(x)$ — кусочно-полиномиальную 
функцию третьей степени, удовлетворяющую условиям:

1. **Интерполяция:** $S(x_i) = y_i$ для всех $i$.
2. **Гладкость:** Непрерывность первой, второй производной сплайна.
3. **Граничные условия (естественный сплайн):** $S''(x_0) = S''(x_{n-1}) = 0$.
На каждом отрезке $[x_i, x_{i+1}]$ сплайн представим в виде
$$S_i(x) = a_i + b_i(x - x_i) + \frac{c_i}{2}(x - x_i)^2 + \frac{d_i}{6}(x - x_i)^3.$$
Коэффициенты $a_i, b_i, c_i, d_i$ определяются через решение трёхдиагональной 
системы линейных уравнений относительно $c_i$.

## План параллелизации
### `computeBD` 
Итерации независимы, каждая пишет в свой индекс массива, за счет чего возможна безопасная параллелизация
### `sweepMethod`
Не параллелится напрямую, так как вычисление происходит последовательно,  но есть возможность ускорения за счёт модернизации деления
### Остальные функции не требуют параллелизации, так как не относятся к вычислительным этапам алгоритма
